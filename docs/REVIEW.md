# 值班复盘

## 交接记录

同一车辆的两段候班时间有交叠时，两份车次同时进入人工点验。正常交接只显示连班记录，里程逆行的影响追溯至下一份调度单。该检查不跨独立车场匹配相同车辆号。

## 电池温控和断路复盘

SOC 曲线按低位、接近上限和高位分段。电池温度会压低可用功率，分析按时间推演每段补电量，并将同分钟多枪去重以避免夸大可用时长。这些记录供值班员核对排班中的保守估计。已报断路和计划停供进入单独复盘，可用计划依然受主操作台当前预算控制。失联馈线单独标注，不作物理断电处理。

## 车辆能耗与电网

气温按冷车、温控运行和常温分段。回收电量占比使用加总后的电量，避免把短距离车辆和满载长班按同一票权相加。历史留出复盘给出各里程桶的残差、预测上界覆盖以及实际超出量。

充电网络同时报告枪位铭牌功率和馈线可用功率。峰值复盘比较每条馈线限额压低至 45、65 和 85 kW 时的处置变化，原排班单不会被比较过程修改。枪账回执按车次、枪位与时格逐项匹配，偏差和验签分别记录。上游计划调整后，旧回执仍可看作实收记录，并显示未登记或计划无回执。
